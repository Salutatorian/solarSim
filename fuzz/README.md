# solarSim Fuzzing Targets

This directory contains the ClusterFuzzLite / OSS-Fuzz compatible fuzzing harnesses for the solarSim native components.

The native layer (`src/SolarSim.Native/`) is a C++ implementation of the solar design engine used by the C# application. It covers electrical graph topology, solar panel definitions, series string calculations, roof geometry, wire routing, and a compact binary project file format.

## Targets

### `solar_module_catalog_fuzzer`

Fuzzes the **Solar Module Catalog (SMC)** binary parser. The SMC format is a compact, native representation of a solar panel module library used by the electrical engine during import of custom module catalogs.

Format:

```
Header (16 bytes)
  magic[4]        "SMC\0"
  version (u32)   1
  module_count    (u32)
  reserved (u32)  0

Module entry
  name_len        (u32)
  name            (name_len bytes)
  pmax            (f64)  STC max power, W
  vmp             (f64)  max-power voltage, V
  imp             (f64)  max-power current, A
  voc             (f64)  open-circuit voltage, V
  isc             (f64)  short-circuit current, A
  vmp_temp_coeff  (f64)  Vmp temperature coefficient, %/C
  width_mm        (u32)
  height_mm       (u32)
  tag_count       (u32)
  tags: for each tag
      tag_len     (u32)
      tag         (tag_len bytes)
```

### `project_file_fuzzer`

Fuzzes the **Solar Project (SOLP)** binary file format. This is a native counterpart to the `.solarproj` JSON file used by the C# application. The format stores site metadata, module definitions, an electrical graph, and roof geometry.

### `roof_geometry_fuzzer`

Fuzzes the 2D roof geometry engine: polygon area, point-in-polygon tests, distance-to-edge, and panel-rectangle containment checks.

Input layout:

```
vertex_count (u32)
4 bytes padding
vertices: vertex_count * (x_mm: f64, y_mm: f64)
```

### `wire_route_fuzzer`

Fuzzes the wire routing and voltage-drop estimator. It parses polyline routes and calculates length, resistance, voltage drop, and ampacity.

Input layout:

```
gauge_awg (u8)
current_amps (u8)
2 bytes padding
points: (x_mm: f64, y_mm: f64)...
```

## Seed corpus

Seeds live in `fuzz/corpus/<target>/`. They are generated by `Tools/generate_fuzzing_corpus.py`.

To regenerate all seeds and PoCs:

```bash
python Tools/generate_fuzzing_corpus.py
```

## Local build

The official build is run by ClusterFuzzLite via `.clusterfuzzlite/build.sh`. It builds all four fuzzer targets and packages their seed corpora.

For a quick local test with libFuzzer (requires Clang):

```bash
mkdir -p out work
export SRC=$(pwd)
export OUT=$SRC/out
export WORK=$SRC/work
export CXX=clang++
export CXXFLAGS="-g -O1 -fsanitize=address,undefined -std=c++17"
export LIB_FUZZING_ENGINE="-fsanitize=fuzzer"
bash .clusterfuzzlite/build.sh

# Run a fuzzer
./out/solar_module_catalog_fuzzer -max_total_time=30 ./fuzz/corpus/solar_module_catalog_fuzzer/
```

## Offline / hermetic build

The build script does not download, install, or access any network resources. It only compiles the sources already committed in this repository.
