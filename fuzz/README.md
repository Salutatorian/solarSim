# solarSim Fuzzing Targets

This directory contains the ClusterFuzzLite / OSS-Fuzz compatible fuzzing harnesses for the solarSim native components.

## Targets

### `solar_module_catalog_fuzzer`

Fuzzes the **Solar Module Catalog (SMC)** binary parser in `src/SolarSim.Native/`.
The SMC format is a compact, native representation of a solar panel module library
used by the electrical engine during import of custom module catalogs.

Format:

```
Header (16 bytes)
  magic[4]        "SMC\0"
  version (u32)   1
  module_count    (u32)
  reserved (u32)  0

Module entry
  name_len        (u32)
  name            (name_len bytes)
  pmax            (f64)  STC max power, W
  vmp             (f64)  max-power voltage, V
  imp             (f64)  max-power current, A
  voc             (f64)  open-circuit voltage, V
  isc             (f64)  short-circuit current, A
  vmp_temp_coeff  (f64)  Vmp temperature coefficient, %/C
  width_mm        (u32)
  height_mm       (u32)
  tag_count       (u32)
  tags: for each tag
      tag_len     (u32)
      tag         (tag_len bytes)
```

The parser validates magic, version, module count, electrical ranges, and dimensions
before building a summary of the catalog (total Pmax and maximum Voc).

## Seed corpus

Seeds live in `fuzz/corpus/<target>/`. They are generated by `Tools/generate_smc_corpus.py`.

To regenerate the seeds and the PoC:

```bash
python Tools/generate_smc_corpus.py
```

## Local build

The official build is run by ClusterFuzzLite via `.clusterfuzzlite/build.sh`.
For a quick local test with libFuzzer (requires Clang):

```bash
mkdir -p out work
export SRC=$(pwd)
export OUT=$SRC/out
export WORK=$SRC/work
export CXX=clang++
export CXXFLAGS="-g -O1 -fsanitize=address,undefined -std=c++17"
export LIB_FUZZING_ENGINE="-fsanitize=fuzzer"
bash .clusterfuzzlite/build.sh

# Run the fuzzer
./out/solar_module_catalog_fuzzer -max_total_time=30 ./fuzz/corpus/solar_module_catalog_fuzzer/
```

## Offline / hermetic build

The build script does not download, install, or access any network resources. It only
compiles the sources already committed in this repository.

## Files

- `src/SolarSim.Native/src/solar_module_catalog.cpp` — parser implementation
- `fuzz/corpus/solar_module_catalog_fuzzer/` — seed corpus
