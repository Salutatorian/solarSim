## Download

**[Windows](https://github.com/Salutatorian/solarSim/releases/download/v1.5.12/solarSim-1.5.12-win-x64.exe)** — double-click it. If Windows blocks it: **More info → Run anyway**.

**[Mac (Apple Silicon)](https://github.com/Salutatorian/solarSim/releases/download/v1.5.12/solarSim-1.5.12-osx-arm64.dmg)** — M1 / M2 / M3 / M4. Open the file, drag to Applications, then right-click → **Open**.

**[Mac (Intel)](https://github.com/Salutatorian/solarSim/releases/download/v1.5.12/solarSim-1.5.12-osx-x64.dmg)** — same steps as Apple Silicon.

Not sure which Mac? Apple menu → **About This Mac**. Chip = Apple → Silicon. Processor = Intel → Intel.
