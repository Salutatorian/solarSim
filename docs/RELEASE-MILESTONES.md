# Milestone releases

GitHub Releases are published in **~10-patch milestones** so the Releases page stays readable.
Patch tags still exist in git for history; only milestone pages stay on Releases.

| Milestone | Covers | Download |
|-----------|--------|----------|
| **v0.1.33** (latest) | 0.1.21 → 0.1.33 | Current Windows zip |
| **v0.1.30** | 0.1.21 → 0.1.30 | Historical |
| **v0.1.20** | 0.1.11 → 0.1.20 | Historical |
| **v0.1.10** | 0.1.0 → 0.1.10 | Historical |

Going forward: ship one public Release every ~10 patches (or when something big ships), not every bugfix.
